# English Journey 11.2 — настоящая речь и свободные диалоги

Добавлен отдельный раздел «Живое аудио и диалоги» и переход к нему из аудирования каждого урока.

- **9 заданий с реальными записями British Council LearnEnglish:** по 3 для A1, A2 и B1. Аудио остаётся у правообладателя и открывается на его странице. Внутри приложения — оригинальные вопросы (по 3 к каждой записи) и сохранение результатов.
- **9 сценариев свободного ответа:** по 3 для каждого уровня, два последовательных ответа в каждом. Ввод текста всегда доступен, необязательная диктовка работает только при поддержке Web Speech API.
- **Проверка свободной речи ограничена:** оценивается узнавание минимальных смысловых элементов в распознанном/написанном ответе; это не проверка произношения, плавности, полноты грамматики, интеракции или CEFR.
- **Без передачи записей приложением на сервер:** приложение не хранит сырое аудио, только текст и статистику в существующем localStorage. *Сервис распознавания речи браузера может обрабатывать звук на серверах браузерного поставщика.*
- Прогресс старых уроков, словарь, зачёты, экзамены и ключ хранилища `englishJourneyTravelV1` не изменяются.
- Синтезированные задания из последних 69 тем остаются частью курса, а раздел с живой речью служит дополнительной тренировкой.
- Для **независимого подтверждения** A2/B1 остаётся необходимым преподаватель/аккредитованный экзамен, а не только результаты приложения.

Материалы для слушания принадлежат British Council LearnEnglish. Сторонние страницы могут быть недоступны в отдельных регионах или измениться.

Критерии выбора треков: страница с аудиозаписью и опубликованной расшифровкой, проверенные факты, явное указание уровня у источника.
