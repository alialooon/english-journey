# English Journey 8.0 — практика навыков

Постоянный адрес: https://alialooon.github.io/english-journey/

Новое: 36 открытых заданий на составление предложений, 12 бытовых текстов с 36 вопросами на понимание, 12 записей разговоров на официальном сайте VOA Learning English и 24 вопроса к ним, 24 варианта ситуативных диалогов (48 реплик). Новые уроки требуют объективной проверки каждого раздела, а ранее завершённые остаются завершёнными. Прежний ключ localStorage `englishJourneyTravelV1` не изменён. Аудио открывается у первоисточника через интернет, сторонние файлы не копируются в репозиторий.

Контроль: 12 тестов по темам, двухэтапный внутренний экзамен после 72 занятий, чтение и настоящее аудирование в тестах. Самостоятельное письмо и выбор реплик диалога не равно оценке свободного говорения и произношения; никаких сертификатов не выдаётся. A2/B1 ещё не созданы. Ориентир ~40 минут, при необходимости урок можно делать дольше.

Проверки: node test_v8.js; Playwright test_v8_browser.py (полный цикл первой темы). Информация по ограничениям: COURSE_AUDIT.md.
