# English Journey — веб-версия 6.0

## Что исправлено
- Дата начала прогноза: **12 октября 2026 года**, вместо некорректного 1970 года.
- Начальный ориентир при 6 уроках в неделю: **A1 — 4 января 2027**, **A2 — 19 июля 2027**, **B1 — 9 октября 2028**. Курсы A2 и B1 пока не созданы: эти даты предварительные.
- После завершения уроков персональный прогноз меняется с учётом скорости и ответов. Исходные даты остаются фиксированными.
- При появлении опубликованной новой версии на сайте будет ненавязчивое уведомление. Обновление запускается кнопкой, чтобы не прерывать задания.

## Один раз подключить автоматическую публикацию

1. Создайте **приватный** репозиторий `english-journey` на https://github.com/new.
2. На странице репозитория выберите **Add file → Upload files** и добавьте **содержимое этой папки** (`index.html`, `style.css`, `course_data.js`, `engine.js`, `version.json`, `netlify.toml`). Затем **Commit changes**. `README.md` тоже можно добавить.
3. В Netlify откройте свой существующий сайт и настройте **Link to Git repository** через страницу конфигурации проекта (если этот вариант доступен в интерфейсе). Укажите GitHub-репозиторий и ветку `main`, публикация из корня (`.`), команда сборки не требуется. Если нет возможности связать существующий сайт, создайте новый через **Add new project → Import an existing project**, подключите GitHub, выберите репозиторий и выполните Deploy. У нового сайта может быть другой URL; перенесите старый прогресс через JSON.
4. Далее каждый раз, когда разработчик/ассистент сохраняет обновлённый код в этом GitHub-репозитории, Netlify публикует новую версию **автоматически**, без скачивания файлов на ваше устройство. В браузере достаточно обновить вкладку либо нажать появившуюся кнопку обновления.

## Важно
- **Автоматическая публикация НЕ означает автоматическое создание кода.** Изменение сначала должно быть внесено в GitHub. Публикация произойдёт только после коммита.
- Прогресс пока хранится в `localStorage` **по адресу конкретного сайта** (ключ `englishJourneyTravelV1`). При обновлениях на том же адресе и в том же браузере он сохраняется. Другой сайт/устройство не синхронизируется до Supabase.
- Перед первоначальной привязкой и крупными изменениями рекомендуется экспорт прогресса через «Настройки».
- Приложение не выдаёт официальный сертификат CEFR. Встроенные тесты — учебные проверки.
- Не публикуйте Supabase `service_role`/secret ключи или пароли в GitHub и браузерном коде.

## Структура
- `index.html` — интерфейс
- `style.css` — оформление
- `course_data.js` — уроки
- `engine.js` — логика, прогнозы, тесты
- `version.json` — указатель текущей опубликованной версии
- `netlify.toml` — правила Netlify, включая отключение устаревшего кэша
