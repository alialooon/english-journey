# English Journey 7.0 — персональный английский для путешествий

**Запуск:** постоянный адрес GitHub Pages: https://alialooon.github.io/english-journey/

**Курс:** 72 готовых занятия вводного модуля A0–A1, темп до 40 минут в день и возможность заниматься быстрее. Последующие модули ещё не созданы.

Новое в версии 7: 574 уникальных слова и выражения, активное вспоминание с вводом с клавиатуры, интервальные повторения, личный словарный раздел и короткое письменное задание в каждом уроке. Предыдущие данные остаются в `localStorage` под тем же ключом. Если пользователь удалит данные браузера, результаты могут пропасть — резервное копирование в меню настроек обязательно до смены устройства.

Ссылки на внешние бесплатные уроки остаются внутри тем. Это не означает, что приложение автоматически скачивает и лицензирует материалы этих сайтов.

**Объективность:** см. [аудит навыков и пробелов](COURSE_AUDIT.md). Внутренний экзамен не является сертификацией A1; для подтверждения CEFR необходима внешняя оценка всех навыков.

**Техническая схема:** статические `index.html`, `engine.js`, `course_data.js`, `vocabulary_data.js`, `vocabulary.js`, `style.css`, `version.json`. Никакой серверной части для этой версии не нужно. В GitHub Pages обновления публикуются при новом коммите в основную ветку.
