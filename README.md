Вход в A2 требует пройденного внутреннего экзамена A1 после 25 тем. Исторические достижения, словарь и результаты сохраняются в localStorage с прежним ключом. Источники звука открываются у British Council; аудиофайлы не копируются. Приложение не выдаёт сертификатов CEFR. Обновления публикуются GitHub Pages автоматически.
