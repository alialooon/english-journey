# English Journey — стандарт качества обучения

**Цель:** сопоставимое с хорошими платными курсами качество содержания и
закрепления навыков. Сходство по количеству уроков, экранов, тестов либо наличие
локального экзамена сами по себе **не доказывают** эффективность курса.
Важнее долгосрочное вспоминание, перенос в незнакомый контекст и способность
самостоятельно пользоваться английским.

## Педагогические правила для каждого обязательного задания

1. **Сначала объяснение.** Для каждого используемого слова, формы и правила
   указывается первый урок обучения. Отдельная ознакомительная фраза
   сама по себе не делает грамматический элемент изученным.
2. **Никаких ответов для списывания.** Учебный пример и самостоятельная
   проверка не совпадают дословно. Сложность возрастает от понятного
   образца к ответу без подсказки.
3. **Понятная задача.** Формулировка по-русски; заранее известны
   язык ответа, контекст, тип действия и критерий правильности.
4. **Разнообразие без случайного усложнения.** Сочетаем распознавание
   значения, самостоятельное воспроизведение, изменение конструкции,
   чтение, диалоги и письмо. В заданиях на слова обязательно появляется
   реальное использование слова в контексте.
5. **Долговременное запоминание.** Встроенное извлечение из памяти через
   интервалы, причём предпочтительно в другой форме и ситуации.
   Слово нельзя считать освоенным после простого просмотра или подсказки.
6. **Без ложных ошибок.** Проверка учитывает допустимые варианты ответов
   и объясняет причину ошибки. Пока локальная проверка не понимает
   вариант, её ограничения указываются честно.
7. **Без ложных успехов.** Подсказка, пропуск или копирование показанного
   ответа не доказывают владения навыком. Ошибка повторяется после задержки.
8. **CEFR как ориентир, не сертификат.** Аудио и распознавание речи
   необязательны для прохождения программы, поэтому внутренний зачёт
   не гарантирует полное владение устным языком соответствующего уровня.
9. **Оригинальность и лицензии.** Используем общие идеи известных методов,
   создаём свои тексты и упражнения. Материалы с открытым доступом
   копируем только при разрешении их конкретной лицензии.
10. **Непрерывность.** Уже зачтённый прогресс сохраняется при обновлении;
    новые требования не обнуляют успешно завершённые уроки.

## Метрики, которые проверяем при выпуске

| Контроль качества | Условие выпуска |
|---|---|
| Предварительное изучение | 0 проверочных элементов, не разобранных до задания; аудит на уровне **каждого дня**, не только темы |
| Уникальность | Упражнения одной недели проверяют разные формулировки; нет прямого показа будущего ответа |
| Грамматическая точность | Проверен смысл русского и английского, вопрос/утверждение, артикли, времена, естественность |
| Разнообразие | В каждой теме минимум три **содержательно разных** действия; не только выбор вариантов |
| Словарь | Новые слова имеют перевод, контекст и отсроченный отзыв; прогресс измеряется спустя дни |
| Ошибки и альтернативы | Нет заведомо неверных эталонов и необоснованного отклонения распространённых корректных вариантов |
| Долговременное удержание | Отдельная диагностика освоения через 1, 7 и 30 дней, не подмена количеством пройденных карточек |
| Техническая надёжность | Автотесты и проверка на мобильном экране, офлайн, миграция и сохранение прогресса |

Указанные условия — **критерии** для следующих этапов, а не заявления,
что весь текущий курс уже их выполняет. Независимый тест обучения
реальными учениками нужен до заявлений об эффективности на уровне
коммерческих платформ.

## Этапы работ

### Этап 1 — встроенное интервальное повторение и контроль качества
- [x] Зафиксировать стандарт качества, контрольные критерии и источники.
- [x] Встроить повторение **только наступивших к повторению** знакомых слов
  в следующий незавершённый урок (не более 3), без слов из будущего.
- [x] Проверка по памяти без готового ответа; при ошибке повтор на
  следующий день, а не повышение уровня освоения.
- [x] Автоматические сценарии на отсроченное повторение, первый урок,
  неправильный ответ и защиту от преждевременных заданий.
- [ ] Пройти тесты браузера и публикацию без регрессий.

### Этап 2 — проверка и расширение содержания A0–A1
- [x] Авторские грамматические схемы и короткая необязательная тренировка их преобразования на первых шести уроках (без полного ответа из проверки).
- [x] Все 48 слов и выражений первой недели получили осмысленные русские ситуации употребления; подсказки доступны при изучении и последующем интервальном повторении.

- [x] Чередование первого грамматического задания в первых 36 уроках: сборка слов и пропуски на специально объяснённых фразах, при сохранении самостоятельного перевода.
- [x] Подсказки первого шестиурочного блока не ссылаются на грамматику будущих уроков.
- Для каждого дня обозначить изучаемые слова, новые правила и
  необходимые предыдущие знания, с автоматическим запретом будущего.
- Увеличить оригинальный банк упражнений, включая порядок слов,
  пропуски, изменение фразы, короткие сообщения и полезные диалоги.
- Добавить контексты для новых слов, устойчивые сочетания и
  приемлемые варианты перевода. Отдельный контроль перегрузки.

### Этап 3 — качественные сценарии A2 и B1
- Устранить 69 шаблонных тем диалогов.
- Перейти от коротких знакомых фраз к оригинальным историям,
  функциональному письму и обучению пониманию смысла.
- Адаптивно чередовать грамматические навыки без будущего материала.

### Этап 4 — эффективность и выпуск
- Аудит всех 600 уроков вручную и автоматически; независимое редактирование
  русских и английских текстов.
- Измерять отсроченные результаты (1/7/30 дней) и исправлять темы с провалами.
- Сравнение по одинаковым исходным знаниям и заданиям с другими курсами.
- Аудирование расширять без обязательного распознавания речи.
