# Audit of English Journey 9.0 versus CEFR

12 October 2026. The CEFR levels are demonstrated performance descriptors rather than an official list of grammar topics. This plan draws on the 2020 CEFR Companion Volume; hours below are indicative from Cambridge English.

| Dimension | A1 current implementation | A2 / B1 state | Still required for a strong school-equivalent outcome |
|--|--|--|--|
| Vocabulary | 978 distinct word and multiword-expression identifiers across 25 A1 themes, active recall and spaced repetition | 25 A2 + 50 B1 topics listed as planned only | Contextual usage checks, productive vocabulary and more natural collocations |
| Grammar | 25 explanations, 75 target-sentence models recycled over 150 sessions, contextual multiple-choice quizzes | Curriculum outline only | Higher variation and acceptance of multiple correct paraphrases; real communicative feedback |
| Reading | 25 original functional texts with 75 fact questions, revisited within lessons and tests | Outline only | More extensive reading with gist/inference and unseen test texts |
| Listening | 25 verified external VOA beginner lesson recordings, 50 comprehension questions | Outline only | More accents, natural-speed speech, unseen audio in assessments |
| Speaking / interaction | 50 branching selection scenarios across themes, no live speech evaluation | Outline only | Real spoken interaction or competent tutor assessment of fluency, appropriateness and accuracy |
| Writing / pronunciation | Short stored writing + user-confirmed speaking | Outline only | Independent rubric-based correction or tutor (outside this expansion) |
| Assessments | 25 mandatory topic tests, remedial activity and next-day retry; intermediate and final internal tests | A2/B1 tests not available | Unseen summative items, anti-cheating and external assessment |
| Guided hours | 150 × up-to-40-minute sessions = theoretical maximum 100 hours (NOT an actual verified study-hour log) | A2 total ~180–200 h, B1 total ~350–400 h by Cambridge guidance | More varied practice, extensive listening and verified productive skills |

A1 remains an ambitious practice path and should not be represented as proven equivalent to school graduation; B1 and A2 are not delivered yet. Failure of internal exam blocks advancement. Every repeated quiz draws questions from a finite bank, so re-exposure can yield memorized answers.

Progress migration: all previous lesson indices, topic-check indices, and saved vocabulary IDs preserved. Historical exam `A1` remains credited to the initial 12-week foundation; the new `A1_full` is separate.
